01 / Apresentação

Sobre mim e o projeto

Sou desenvolvedor back-end e estudante de tecnologia. Tenho interesse em entender como os sistemas funcionam e em criar soluções que ajudem as pessoas em suas atividades.

Este portfólio começou como minha primeira página da disciplina, criada com HTML5. Na segunda entrega, usei CSS3 para adaptar o layout a diferentes telas. Nesta terceira entrega, usei JavaScript para validar o formulário de contato e contar os caracteres da mensagem.

    Nesta API em C# com ASP.NET Core, é possível cadastrar, consultar, atualizar e excluir pizzas. Quando uma pizza não existe, a consulta por ID devolve o código HTTP 404.

    Neste cadastro em Ruby on Rails, cada criptomoeda ocupa uma linha da tabela coins no SQLite. A tabela guarda a descrição, a sigla e o endereço da imagem de cada moeda.
